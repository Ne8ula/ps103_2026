# Home, Bambu projects and Collection

**Four new visual mockups, inspected. No application code changed.** This revision replaces the ivory/orange/serif direction with cool pearl, graphite and restrained violet. It responds to the user's request for main-page navigation, collection screens and much clearer glass/matrix effects.

## Proposed navigation

| Starting point | Action | Destination |
|---|---|---|
| Home | View projects on the Bambu card | Bambu projects |
| Bambu projects | Little cat card | Little cat detail |
| Little cat detail | Start this project | Existing guided project sequence |
| Home | Your collection row or Collection tab | Collection / Saved |
| Project detail | Save bookmark | Saved state in Collection |
| Collection / Saved | Little cat card | Project detail, retaining Collection as navigation origin |
| Any browsing screen | Home tab | Home |
| Collection | Made tab | Proposed completed-project view; not rendered in this packet |

The detail mockup shows Home active because it was entered from Bambu projects. A detail page entered from Collection should retain that origin and return there. This is proposed navigation, not an implemented router or working bookmark system.

The cat remains the one authored guided demo. Ripple tray and Cable pebble are explicitly labeled Preview: illustrative collection content, not existing instructions, printable assets or validated projects. Preview cards should open preview information, not a misleading Start action.

## Visual changes

- Cool pearl base, graphite image fields and actions, violet navigation accents. Regular-width sans throughout; no ivory/orange or serif identity.
- Frosted sheets overlap the rendered objects. Silhouettes remain visible, blurred and refracted through the foreground glass, with doubled highlights and tangible edges.
- One portion of each project object resolves into a visible character field with ordered dot shading and a sparse sampling grid. This is stronger than r6's perimeter treatment.
- Effects stay inside media. Labels and controls remain crisp. Project art may be expressive; any future inspection-photo effect must preserve an unaltered image and must not imply verified sensing.
- A consistent Home/Collection dock supplies stable navigation. Task detail retains one Start action and one optional requirements disclosure.

Generated headings remain more prominent than the nominal 25px prompt target. Exact type size, material contrast, text scaling and touch-target validation belong to native component implementation, not the raster reference. The cat shape and printer are generated representations, not new 3D assets or mechanically verified hardware.

## Reference use and generation

The previously supplied video contact sheet was the first call's only direct image input, used for object-following character density. Its warm colors and poster typography were excluded. The Claryx and ASCII flower references were described as text roles; their original inline files were not passed in this revision. r6 and earlier app boards were excluded from the new design.

Three built-in image calls:
1. Home/Bambu draft: the material treatment succeeded, but the screens were too elongated. Retained as a [discarded proportion study](images/01a-home-bambu-tall-study.png).
2. Targeted layout correction using that new draft: restores realistic phone proportions, removes a duplicated collection card and retains the selected material treatment. This is the delivered Home/Bambu board.
3. Project/Collection using the corrected new board plus the video contact sheet for continuity.
