## Result

Purple remains primary. Citron is the proposed secondary accent, used in action end-caps, bookmarks, avatar edges and progress details. Cool pearl and graphite preserve contrast. Normal-width sans and the same sculptural cat continue from r7.

Matrix treatment now appears outside the image: frosted panel edges, section dividers, selected-tab markers, Saved/Makes underlines, the profile avatar halo and journey indicators. Text and icons remain solid and readable. In an implementation, these motifs should remain static or respect reduced motion, and should never be the sole indication of state.

The four-tab dock is consistent: **Home / Collection / Community / Profile**. Home still opens Bambu projects through View projects; the r7 Bambu/detail concepts remain the reference for that nested route, with the new shared palette/navigation to be applied if implemented.

Community includes Makes / Questions, one illustrative maker story, Appreciate / Discuss, an Ask the community entry and Share a make. “Jules” and the story are fictional example content. Profile includes an unnamed editable identity, selected X1 Carbon, a proposed unstarted cat journey and settings entries. These are visual concepts, not actual account state, live community activity or a saved profile.
