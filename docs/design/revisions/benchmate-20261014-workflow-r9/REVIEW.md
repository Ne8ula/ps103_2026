The user's requested copy rule is applied throughout the selected concept screens: headers and subtitles start Every Word With A Capital Letter and contain no periods. The Benchmate wordmark is capitalized. Ordinary instructional body prose is not required to be Title Case.

The two r8 boards are the visual references for all eight initial generations. They carry the purple/citron palette, pearl glass, graphite hierarchy, sculptural cat and matrix patterns in both images and components. Earlier rejected blue and ivory/orange directions were not reintroduced.

Board 08 contains independent Community/Profile destinations and a paused first-layer checkpoint; the paused state is not a step after project completion.

Browsing uses Home, Collection, Community and Profile. Active guidance concentrates on the current task with Back and Help, a phase rail, optional expanded detail and one dominant action. Collection stores the conceptual result; the optional share composer leads to Preview Post, not automatic publication.

## Inspection And Corrections

All selected images were visually inspected. Titles/subtitles were checked against [screen-map.json](screen-map.json). Optional expanded guidance is visible on the plate, possible-finding and cooling screens. Matrix patterns appear on imagery, panel edges, dividers, selected tabs and phase rails.

Eight initial boards were generated. Seven bounded correction calls fixed missing earlier-phase completion marks, the consistency of the first-layer photo, helper-caption capitalization, disclosure direction, recovery rails/open-issue status, printing and completion indicators, and the saved pause checkpoint. Initial outputs remain alongside the selected finals. The final photo sequence uses the same loose first-layer patch in capture, processing and possible finding.

The generated plate view in board 02 is a display of the plate rather than a precise demonstration of its seated position. Printer geometry, spool routing, cleaning props and printed supports are illustrative. Replace them with verified task assets before shipping. Some heading scale and spacing vary between boards; implement the intended type system in native components and check contrast, text scaling and touch targets there.

## Boundaries

- These are 24 static iPhone concept screens, not a native iOS implementation or proof of interaction behavior
- Camera, processing and possible finding are labeled demonstrations; no user photo was analyzed
- No printer is connected or controlled, and no physical print was validated
- Community content is fictional; no profile, account, post or message was created
- Settings, discussions and the final post preview/publish view are not shown
- App source remains unchanged; all six baseline source hashes match in [source-integrity.json](source-integrity.json)
