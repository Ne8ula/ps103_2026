# Focused progression — concepts before code

Both specifically approved runs have now completed. This is the retained pre-run brief; see the [actual comparison and review](REVIEW.md). No application code has changed.

User direction: stronger contrast, meaningful accents, unmistakable hierarchy, fewer visible choices, simple step-by-step gamified UI inspired by Duolingo, with aesthetic 3D and frosted materials. The user explicitly wants to review Weave concepts before further code edits.

## Fixed constraints

- Real original 3D cat; all nine reference roles in both exact prompts.
- One dominant action per task. Strong dark heading, readable task text, quiet progress context.
- Help, sources, saving, detailed progress and model controls no longer compete with the main action.
- A concise five-chapter journey groups necessary microsteps; do not skip physical checks or promise five taps.
- Gamification acknowledges recorded checks: an earned mark, visible progress, personal finish. No streak pressure, points, penalties, fake sensing or physical-safety awards.
- Warm mineral-white, dark slate, saturated glacier teal action, peach/orange accents and thick cloudy glass.
- Four static states per board: plate task, chapter checkpoint, recovery, personal finish. No motion implementation proposed.
