BenchMate street poster

BenchMate-Street-Poster.png — flat artwork, 3600 x 2250 pixels, 8:5 landscape.
poster.html — self-contained editable source, local font and original brand SVGs embedded.
BenchMate-Street-Mockup.png — generated placement preview in the supplied street photo.
mockup-prompt.txt — exact prompt supplied to the built-in image_gen tool.
build-poster.mjs — rebuilds the poster from existing brand assets using Chromium.

Design: current blue BenchMate wordmark and Soft Joint symbol, Space Grotesk
headline, pale cloud background, lime accent, dithered folded planes and a large
dithered ribbon across the bottom. Clear space separates the message from graphics.
Copy: Guided projects. From idea to made.

The flat artwork preserves the exact original vector marks. The scene mockup was
produced with the built-in image_gen editing tool using the original street photo
and finished flat poster as inputs. It is a generated placement preview, not a
pixel-preserving edit of the 7952 x 5304 source photograph. Use the flat PNG or
editable HTML as the artwork master. Physical print dimensions and bleed were
not specified. The original photograph was not modified.

Rebuild from repository root:
  node docs/brand-guide/street-poster/build-poster.mjs
